# Image Replacement Guide

Current product visuals are original UI components rather than stock imagery. Replace or add photography under:

- `public/images/industries/`
- `public/images/company/`
- `public/images/resources/`
- `public/images/product/`
- `public/images/integrations/`

Use real, relevant images: manufacturing floors, production planning teams, warehouse operations, barcode scanning, quality inspection, garments production, retail POS, distribution logistics, construction operations, and dashboard review sessions.

Avoid robot imagery, holograms, electronic chips, distorted people, and generic office photos.
