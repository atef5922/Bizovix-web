# Content Management Guide

Main content lives in:

- `src/data/navigation.ts`
- `src/data/solutions.ts`
- `src/data/industries.ts`
- `src/data/pricing.ts`
- `src/data/faqs.ts`
- `src/data/resources.ts`
- `src/data/blog.ts`
- `src/data/integrations.ts`
- `src/data/workflows.ts`
- `src/data/company.ts`

Update these typed files first. Menus, route templates, filters, sitemap entries, and detail pages reuse this data.
