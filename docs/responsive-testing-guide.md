# Responsive Testing Guide

Check major routes at 320, 360, 375, 390, 430, 768, 820, 1024, 1280, 1366, 1440, 1600, and 1920 pixel widths.

Verify:

- No horizontal overflow
- Navigation drawer and desktop menus are keyboard and touch usable
- Dashboard cards and charts remain readable
- Forms fit one column on mobile
- CTA buttons remain visible
- Footer columns wrap cleanly
- Cookie bar does not hide primary actions on small screens
- Reduced motion is respected
